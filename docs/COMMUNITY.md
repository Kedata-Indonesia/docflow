# Community — DocFlow

Welcome to the DocFlow community! Whether you are embedding the editor in an
enterprise application, building local document tooling, or contributing bug
fixes, we are glad you are here.

## Channels

- **GitHub Discussions** — [github.com/Kedata-Indonesia/docflow/discussions](https://github.com/Kedata-Indonesia/docflow/discussions)
  - Q&A, ideas, and RFCs — e.g. the React wrapper, PDF export quality, and
    bilingual (ID/EN) `kop surat` templates.
- **GitHub Issues** — [github.com/Kedata-Indonesia/docflow/issues](https://github.com/Kedata-Indonesia/docflow/issues)
  - Report bugs or request features. Please search existing issues before opening a new one.
- **Discord** — *coming at launch; invite URL pending*
  - Real-time chat with maintainers and other developers embedding DocFlow, plus a
    **#showcase** channel to share what you are building.

## Code of Conduct

We follow the [Contributor Covenant (version 2.1)](../CODE_OF_CONDUCT.md). By
participating, you agree to uphold this code. Please treat fellow community
members with respect and professionalism.
